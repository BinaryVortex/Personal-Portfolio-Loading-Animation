# Personal Portfolio Loading Animation

A small, clean loading animation designed for a personal portfolio or landing page. Built with plain HTML and CSS — easy to drop into any project.

![Screenshot](./Screenshot%202024-09-19%20160759.png)

## Overview

This repository contains a lightweight loading animation demo used in a personal portfolio. It demonstrates simple, performant CSS animations and layout techniques that are easy to customize.

## Features

- Pure HTML & CSS (no JavaScript required)
- Minimal and responsive layout
- Easy to customize colors, size, and animation speed
- Includes a demo page (index.html) and stylesheet (style.css)

## Preview

See the screenshot above for a preview. To view the live animation, open `index.html` in your browser or serve the folder with a static server.

## How to run

1. Clone this repository:

   git clone https://github.com/BinaryVortex/Personal-Portfolio-Loading-Animation.git

2. Open `index.html` directly in your browser, or serve with a simple HTTP server:

   - Python 3: `python -m http.server 8000`
   - Node (http-server): `npx http-server`

3. Navigate to `http://localhost:8000` (if using a server) or open the file in your browser.

## Customization

Edit `style.css` to change colors, size, or animation timing. Common places to tweak:

- Color variables or `.loader`/`.dot` background properties
- `width` / `height` of the loader container
- `animation-duration` to speed up or slow down the effect
